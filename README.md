# Customer Churn Prediction

A machine learning project for predicting customer churn using a Random Forest classifier.

## Features

- Exploratory Data Analysis
- Data preprocessing
- Feature engineering
- Random Forest classification
- Churn probability prediction
- Flask web application

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Bootstrap

## How to Run

```bash
pip install -r requirements.txt
python app.py
